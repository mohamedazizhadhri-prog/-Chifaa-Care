═══════════════════════════════════════════════════════════════
   🎯 QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Can't connect to database
Solution:
  1. Check internet connection
  2. Run: node test-neon-connection.js
  3. Verify DATABASE_URL in .env file

Problem: Port already in use (3000 or 4200)
Solution:
  1. Close other applications using these ports
  2. Or change PORT in backend/.env

Problem: Dependencies missing
Solution:
  1. Run: VERIFY-SETUP.bat
  2. It will auto-install missing packages
