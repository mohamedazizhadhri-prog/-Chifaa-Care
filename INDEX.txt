  🎯 PRIMARY SCRIPTS (Use These!)
  ─────────────────────────────────────────────────────────

  ⚙️ setup-database.bat
     First-time database setup
     • Installs dependencies
     • Connects to Neon database
     • Creates all tables
     RUN ONCE: First time only

  🚀 start-all.bat
     Start both servers
     • Opens 2 terminal windows
     • Backend + Frontend
     • Browser opens automatically
     RUN ALWAYS: Every time you develop

  ✅ check-system.bat
     Health check
     • Verifies Node.js
     • Checks dependencies
     • Tests database
     • Shows what's missing
     RUN ANYTIME: When something breaks


  🔧 INDIVIDUAL SERVER SCRIPTS (Optional)
  ─────────────────────────────────────────────────────────

  ⚙️ start-backend.bat
     Backend server only (Port 3000)

  ⚙️ start-frontend.bat
     Frontend server only (Port 4200)


  ┌────────────────────────────────────────────────────────────┐
  │                   💻 NPM COMMANDS                            │
  └────────────────────────────────────────────────────────────┘

  STARTING SERVERS
  ─────────────────────────────────────────────────────────
  npm start              → Frontend only
  npm run backend        → Backend only
  npm run start:all      → Both (calls start-all.bat)

  DATABASE
  ─────────────────────────────────────────────────────────
  npm run db:setup       → Setup database
  npm run db:studio      → Open database GUI
  npm run db:test        → Test connection

  COMPLETE SETUP
  ─────────────────────────────────────────────────────────
  npm run setup          → Full setup (all deps + db)

  DEVELOPMENT
  ─────────────────────────────────────────────────────────
  npm run build          → Production build
  npm run dev            → Dev mode
  npm run watch          → Watch mode

  ┌────────────────────────────────────────────────────────────┐
  │                   🐛 TROUBLESHOOTING                         │
  └────────────────────────────────────────────────────────────┘

  SOMETHING BROKEN?
  ─────────────────────────────────────────────────────────
  Step 1: Run check-system.bat
  Step 2: Read error messages in terminals
  Step 3: Check QUICK_START.md troubleshooting section
  Step 4: Check START_HERE.md for detailed fixes

  COMMON FIXES
  ─────────────────────────────────────────────────────────
  Port in use:
    netstat -ano | findstr :3000
    taskkill /PID <number> /F

  Database error:
    npm run db:test

  Module not found:
    npm install
    cd chifaacare-backend && npm install

  Prisma error:
    cd chifaacare-backend
    npm run prisma:generate
