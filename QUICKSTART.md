# Quick Start Guide - Ramix Discord Controller

## Get Started in 3 Minutes!

### 1️⃣ Get Your Webhook (2 minutes)
1. Open Discord
2. Go to your server
3. Right-click a channel → "Edit Channel"
4. Click "Integrations" → "Webhooks" → "New Webhook"
5. Click "Copy Webhook URL"

### 2️⃣ Configure Ramix (30 seconds)
1. Right-click `ramix.bat` → "Edit"
2. Replace `YOUR_WEBHOOK_URL_HERE` with your URL
3. Save and close

### 3️⃣ Run It! (30 seconds)
1. Double-click `ramix.bat`
2. Choose option 1
3. Type a message
4. See it appear in Discord!

## What You Can Do

✅ **Send Messages** - Instant messages to your Discord channel
✅ **Announcements** - Formatted announcements with emoji
✅ **Events** - Create event notifications with time and details
✅ **Embeds** - Beautiful colored embed messages
✅ **Activity Tracking** - Monitor your bot activity
