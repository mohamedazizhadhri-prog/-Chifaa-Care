## 🎬 TRIGGERS (When Overlay Shows)

    1️⃣  ON PAGE LOAD
         │
         ├─→ Wait 1 second
         └─→ 💥 SHOW OVERLAY


    2️⃣  ON SCROLL
         │
         ├─→ User scrolls down
         ├─→ Reaches 50% of page
         └─→ 💥 SHOW OVERLAY


    3️⃣  PERIODIC (Every 3 Minutes)
         │
         ├─→ User browsing website
         ├─→ 3 minutes pass
         └─→ 💥 SHOW OVERLAY (if not already visible)

## 🎯 USER FLOW EXAMPLE

    1. User visits website
       └─→ ⏱️ Wait 1 second
           └─→ 💥 Overlay appears!

    2. User sees Slide 1 (Welcome - 30% OFF)
       └─→ ⏱️ After 4 seconds
           └─→ 🔄 Auto-switch to Slide 2

    3. User sees Slide 2 (Deals - Buy 2 Get 1)
       └─→ Options:
           ├─→ Click [Claim Offer] → Navigate to offers page
           ├─→ Click [X] → Close overlay
           ├─→ Press ESC → Close overlay
           └─→ Click dots → Go to specific slide

    4. User closes overlay
       └─→ ✅ Continue browsing

    5. User scrolls down page
       └─→ Reaches 50% scroll
           └─→ 💥 Overlay appears again!

    6. User continues browsing
       └─→ ⏱️ After 3 minutes
           └─→ 💥 Overlay appears again!
